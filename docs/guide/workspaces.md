# Workspaces

This page is for the person who writes notes.

A workspace is a separate set of notes. Your personal notes and your work
notes can live in two workspaces, so one never appears while you read the
other.

## What a workspace keeps apart

A workspace holds its own notes, its own folders, its own Trash, its own
published links and its own history. The note list, the search answer, the
command palette and the backlink panel each show one workspace: the one you
have open.

A folder does not do this. A folder groups notes inside one workspace, and
every one of those notes is still in the list. Use a folder to group. Use a
workspace to separate.

## Your first workspace

Your account starts with one workspace, named Personal. Every note you have
made so far is in it. You can rename it.

## Switch between workspaces

The name of the open workspace is at the top of the sidebar. Select it to see
every workspace of your account. Select a workspace to open it.

The command palette can also do this. Press Cmd or Ctrl and P, then type the
name of the workspace.

Each device remembers the workspace you last opened, so a second device can
stay on a different one.

## Make a workspace

Select the workspace name at the top of the sidebar, then select New
workspace. Give it a name and select Make workspace.

The new workspace opens and it is empty. Select New note to fill it.

## Rename a workspace

Select the workspace name at the top of the sidebar, then select Rename
workspace. The notes do not change.

## Delete a workspace

Select the workspace name at the top of the sidebar, then select Delete
permanently. Type the name of the workspace to confirm.

Every note, every version and every published link of that workspace goes.
Trash does not hold them, and you cannot get them back. Export the notes
first if you want to keep them. See [Export](export.md).

Your account always keeps one workspace. Delete permanently is not offered
when you have only one.

## What a workspace does not do

- A link between notes works inside one workspace. A note cannot link to a
  note in another workspace.
- Search reads the workspace you have open. To find a note in another
  workspace, open that workspace first.
- A note cannot move between workspaces. Export it and write it again in the
  other workspace.
