# 0233. Contributions do not require sign-off

- Status: Accepted
- Date: 2026-10-23

## Context

The contribution guide accepts changes under AGPL-3.0-only with no required
Developer Certificate of Origin sign-off. Earlier records still describe a
sign-off requirement and a required Sign-off check.

## Decision

Contributions use AGPL-3.0-only. No contributor license agreement or DCO
sign-off is required. A missing `Signed-off-by` line does not block a change.

This replaces the sign-off requirement and DCO check in record
[0188](0188-the-repository-opens-under-agpl-3-0-only.md), and the DCO guidance
in records 0223, 0224 and 0228. The license and the boundary between core and
cloud stay the same.

## Consequences

The README, contribution guide and launch guide use the same contribution
terms. Earlier records and design 024 keep their context and point here for
the current sign-off policy.
