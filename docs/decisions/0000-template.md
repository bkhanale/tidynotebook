# 0000. Title of the decision

- Status: Proposed
- Date: YYYY-MM-DD

## Context

State the problem. Name the code that the problem touches. Give the facts
that force a choice, not the choice itself. Keep this to a few sentences.

## Decision

State the choice in the present tense. Name the package, the file, or the
command that carries it. State what the choice excludes.

## Consequences

List what becomes easier, what becomes harder, and what the gate now
refuses. Name the test or the check that holds the decision in place.
