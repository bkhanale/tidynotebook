# 0234. Public issues are the work entry point

- Status: Accepted
- Date: 2026-10-23

## Context

The board address in the active documentation is not available to public
readers. The active documentation links to the public issue list and no longer
claims that board order defines priority.

## Decision

Use [Open issues](https://github.com/tidynotebook/tidynotebook/issues) as the
public entry point for open work. Issue list order does not define priority.
Milestones, priority labels, and area labels describe the intended work.
This replaces the public work-list and ordering guidance in
[decision 0027](0027-track-work-on-the-github-board.md).

## Consequences

The active documentation links to a public list that visitors can open.
The tracking page explains issue details. Earlier records retain their
original board links as history.
