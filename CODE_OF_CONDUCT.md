# Code of conduct

This project welcomes people with different skills and backgrounds. These
rules apply to issues, pull requests, discussions and other project spaces.
They also apply when a person acts for this project in another space.

## Work together

- Treat each person with respect.
- Discuss the work. Explain a problem with facts and clear examples.
- Accept useful feedback. Give other people time to answer.
- Keep private information private. Get consent before you publish it.
- Help new contributors understand the project rules.

## Unacceptable conduct

- Threats, harassment or discrimination.
- Sexual content or unwanted sexual attention.
- Personal attacks or repeated hostile comments.
- Publication of private information without consent.
- Spam or repeated disruption of project work.

## Report a problem

Send a report to [hello@bhushankhanale.com](mailto:hello@bhushankhanale.com).
Include what happens, where it happens and any evidence. Do not put private
information in a public issue. For a security problem, use
[SECURITY.md](SECURITY.md).

The repository owner handles reports. The owner limits access to report
details to the people who need them. The owner can remove content, give a
warning, limit access or block a person. The action depends on the harm and
whether the conduct continues. You can ask the owner to review an action
through the same private contact.
